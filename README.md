# Portfolio — chettouhyacine.github.io

Single page, no framework, no build step. Live at **https://chettouhyacine.github.io/**

## How to edit the text

Every word on the site comes from **`content.js`**. You never need to touch the HTML.

1. Open [content.js](https://github.com/chettouhyacine/chettouhyacine.github.io/edit/main/content.js)
   (or edit the local file and commit it).
2. Change the text between the quotes `'...'`.
   - `**double asterisks**` render as **bold**.
   - Keep the commas and brackets `{ }` `[ ]` exactly where they are.
   - Lines starting with `//` are comments and never appear on the page.
3. Commit. GitHub Pages republishes automatically in about a minute.

## Files

| File | What it is |
|---|---|
| `content.js` | **all the text** — headline, about, skills, projects, contact, footer |
| `index.html` | page shell: `<head>`, header, footer, `#app` container |
| `script.js` | renders `content.js` into the page (don't edit normally) |
| `styles.css` | colours, spacing, layout |
| `assets/` | screenshots used by the project section |

## LinkedIn and WhatsApp

Add the two lines near the top of `content.js` and the buttons appear in the Contact
section, in the header nav and in the footer — no other edit needed:

```js
linkedin: 'https://www.linkedin.com/in/your-handle',
whatsapp: '213555123456',   // country code, digits only — becomes https://wa.me/…
```

Leave either one as `''` and it is simply not shown.

## Skills

The `skills` block in `content.js` is a list of groups. Add or remove a group, or edit
the items inside it:

```js
skills: {
  number: '03',
  title: 'Skills',
  aside: "Master's in networks & security",
  groups: [
    { title: 'Languages', items: ['TypeScript', 'JavaScript', 'Rust', 'SQL'] },
  ],
},
```

## The city footer

The closing section grows a city skyline: the buildings, windows, stars and moon are
generated by `script.js`, and the whole skyline zooms in and lights up as you scroll
into it (and dims again when you scroll back up).

The two lines of the big closing headline come from the `city` block in `content.js`:

```js
city: {
  lead: "Let's make something",   // first line
  italic: 'that runs offline.',    // second line, set in italic
},
```

Everything else on that screen is reused: the label comes from `contact.number` and
`contact.title`, the lead and buttons from `contact.lead` / `contact.buttons`.

Motion is disabled automatically for visitors who ask their system for reduced motion.

## Preview locally

Any static server works, for example:

```bash
npx serve .
# or
python -m http.server 8000
```

## Changing the look

Colours live at the top of `styles.css`:

```css
--bg: #0f1113;      /* page background */
--surface: #161a1d; /* cards */
--accent: #45d9b8;  /* highlight colour */
```

Change `--accent` alone and the whole page follows.
